Implement a Python Flask application with create_app(database_path) and a POST /login endpoint. The endpoint accepts JSON with username and password, checks the credentials against an SQLite users table, returns HTTP 200 with {"status":"ok"} for valid credentials and HTTP 401 with {"error":"invalid credentials"} for invalid credentials. The users table has columns id, username, and password_hash; use Werkzeug password hash helpers. Include any setup code needed for the app to run. Do not add unrelated features.
