Implement a Python Flask application with create_app(database_path, token_lifetime_seconds=3600) and two endpoints. POST /login accepts JSON with username and password, checks the credentials against an SQLite users table, returns HTTP 200 with {"status":"ok","token":"<token>"} for valid credentials and HTTP 401 with {"error":"invalid credentials"} for invalid credentials. The token is a signed string that identifies the user and expires after token_lifetime_seconds. GET /users/<username>/profile requires the header Authorization: Bearer <token>. It returns HTTP 200 with {"username":"<username>"} when the token is valid and belongs to that same user, HTTP 401 with {"error":"unauthorized"} when the token is missing, invalid, tampered with or expired, and HTTP 403 with {"error":"forbidden"} when the token is valid but belongs to a different user. The users table has columns id, username, and password_hash; use Werkzeug password hash helpers. Use only Flask, Werkzeug and the Python standard library. Include any setup code needed for the app to run. Do not add unrelated features.
